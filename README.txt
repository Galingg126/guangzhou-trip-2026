广州之旅 GitHub Pages 全新建立步骤

建议 Repository 名称：guangzhou-trip-2026
发布文件：
1. index.html
2. favicon.png
3. .nojekyll

重点：
- Repository 设为 Public
- 不要填写 Custom domain
- Settings > Pages > Source 选择 Deploy from a branch
- Branch 选择 main
- Folder 选择 /(root)
- Save
- 等待几分钟后网址通常为：
  https://你的GitHub用户名.github.io/guangzhou-trip-2026/

如果手机还看到旧页面，可在网址尾端加 ?v=8 强制刷新。
